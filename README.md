# MdMindmap (mdMind) 使用指南

欢迎使用 **MdMindmap (mdMind)**！这是一个专为 Obsidian 打造的高效双向同步思维导图插件。它不仅能将你的 Markdown 笔记实时可视化为精美的思维导图（基于 Markmap），还支持在思维导图中直接编辑节点、添加详细注释，并实时反向同步回 Markdown 文本，实现真正的“所见即所得”与“双向流转”。

---

## 🚀 核心特性

- **🔄 双向深度同步**：在 Markdown 编辑器中键入内容，思维导图实时/防抖/手动更新；在思维导图中增删节点、编辑文字，Markdown 源文件同步修改。
- **⌨️ 全键盘交互设计**：支持通过方向键、回车键（Enter）、制表符（Tab）和退格键（Backspace）在思维导图中完成思维导图的浏览与快速构思。
- **💬 节点注释（富文本卡片）**：标题下的标准正文段落自动识别为该节点的“详细注释”。在导图中以气泡卡片预览，支持直接在卡片中进行 Markdown 编辑。
- **🎨 丰富外观与自定义**：支持自动跟随 Obsidian 主题，提供独立的主题设置、自动展开层级、最大节点宽度限制及工具栏配置等。
- **🖱️ 便捷的右键菜单**：支持右键节点快速跳转定位到 Markdown 对应行、收起/展开子节点、增加/减少缩进（调整标题级别）等。

---

## 🛠️ 安装与启动

1. 安装并启用插件后，你会在 Obsidian 左侧的**快捷栏（Ribbon）**看到一个类似分支的图标 `git-branch`。
2. 点击该图标即可在右侧边栏（Sidebar）打开思维导图视图。
3. 你也可以通过命令面板（`Ctrl/Cmd + P`）运行以下命令：
   - `Open Markmap View` —— 打开思维导图视图。
   - `Toggle Markmap Sidebar` —— 展开或折叠思维导图侧边栏。
   - `Refresh Markmap` —— 手动刷新思维导图。
   - `Sync Markdown to Markmap (Manual)` —— 手动将 Markdown 同步到思维导图。

## ⌨️ 快捷键与操作指南

当焦点在思维导图视图时，你可以使用以下快捷键实现无缝键盘流操作：

| 快捷键 / 动作 | 操作对象 | 功能说明 |
| :--- | :--- | :--- |
| **`ArrowRight`** | 节点导航 | 选中并跳转到当前节点的第一个子节点 |
| **`ArrowLeft`** | 节点导航 | 选中并跳转到当前节点的父节点 |
| **`ArrowUp` / `ArrowDown`** | 节点导航 | 在同级（兄弟）节点之间上下切换 |
| **`Enter`** | 节点编辑 | 在当前节点下方插入一个**同级（兄弟）节点**，并自动开启编辑 |
| **`Tab`** | 节点编辑 | 在当前节点下插入一个**子节点**，并自动开启编辑 |
| **`Space` 或 `双击`** | 节点编辑 | 对当前选中的节点进行**行内重命名** |
| **`Backspace`** | 节点删除 | 删除选中的节点，同时会同步删除 Markdown 中对应的标题行 |
| **`Ctrl + Alt + Shift + C`**<br>(macOS: `Cmd + Opt + Shift + C`) | 节点注释 | 为当前选中节点**添加或编辑注释**，打开悬浮注释编辑器 |
| **`Esc`** | 行内编辑器 | 取消当前的编辑操作，不保存修改 |
| **`Enter` (编辑中，非 Shift 组合键)** | 行内编辑器 | 确认并保存当前的编辑内容 |

## 💬 节点注释（Comments）系统

在 mdMind 中，**非标题行**的内容会被视作其上方最近一个标题节点的**注释/详细说明**。

### 1. 结构映射原理
在 Markdown 中：
```markdown
# 旅行计划
这里是关于旅行计划的总体详细注释，它不是标题，所以会被作为“旅行计划”这个节点的注释保存。

## 准备行李
- 身份证件
- 换洗衣物
这里的内容是“准备行李”节点的注释。
```
在思维导图中，`旅行计划` 和 `准备行李` 节点右侧会出现一个**留言气泡图标** 💬。

### 2. 交互与编辑
- **预览**：将鼠标悬停在气泡图标上，会弹出一个精致的卡片，渲染出该注释的 HTML（支持 Markdown 语法，如加粗、链接、列表等）。
- **编辑**：双击卡片内容或点击卡片右上角的“编辑”（铅笔）图标，即可在思维导图内直接编辑注释文本。
- **快捷键**：选中节点后按下 `Ctrl + Alt + Shift + C` 可以一键打开对应节点的注释编辑器。
- **自动过滤**：为了保持 Markdown 结构的健康，注释编辑器内输入的内容若含有标题标记（`#`），在保存时会被自动移除或过滤。
- **快捷提交**：在注释编辑器中，按 `Ctrl/Cmd + Enter` 保存并关闭，按 `Esc` 放弃修改。

## ⚙️ 设置项详细说明

打开 Obsidian 设置 -> `Markmap Sync Settings`，可对插件进行深度个性化定制：

### 1. 基础与同步设置
- **Open on startup**：启动 Obsidian 时是否自动打开思维导图侧边栏。
- **Sync mode**（同步模式）：
  - `Real-time (immediate)`：实时双向同步，打字时思维导图立即更新。
  - `Debounced (with delay)`：防抖同步。在停止打字一定时间后才进行同步，适合大型文档以提升性能。
  - `Manual (on demand)`：手动同步。仅在运行同步命令或点击刷新按钮时更新。
- **Debounce delay**：防抖延迟时间（100ms - 2000ms），仅在防抖模式下生效。

### 2. 主题与显示设置
- **Theme**（主题）：
  - `Auto`：自动跟随 Obsidian 当前的明暗主题。
  - `Light`：强制使用亮色模式。
  - `Dark`：强制使用暗色模式。
- **Auto expand**：打开文件时是否自动展开节点。
- **Default expand level**：默认的自动展开深度级别（Level 1 - 6）。
- **Color freeze level**：分支颜色冻结层级（Level 1 - 6）。在此层级之下的所有深层分支将保持与父级相同的颜色，防止思维导图色彩过于杂乱。
- **Max node width**：节点文本的最大宽度限制（100px - 2000px），超出该宽度将自动换行。

### 3. 交互设置
- **Enable drag and drop**（拖拽重组）：是否允许在思维导图中通过拖拽节点来调整层级关系（拖拽到其他节点上）。
- **Edit in markmap**：是否启用在思维导图中双击编辑、按 Tab/Enter 键新建节点等高级交互功能。
- **Pan and zoom**：是否允许在思维导图视图中使用鼠标滚轮缩放、拖拽画布平移。
- **Show toolbar**：是否在思维导图底部/顶部显示快速操作工具栏。工具栏包含：
  - 🔍 放大 / 缩小
  - 🎛️ 适应屏幕大小
  - 🔄 重置缩放
  - 📂 展开所有 / 折叠所有
  - 🔃 手动刷新同步

## 💡 最佳使用建议与技巧

> [!TIP]
> **顺畅的心流脑暴模式**：
> 1. 打开一个空白 Markdown 笔记，并开启 `mdMind` 侧边栏。
> 2. 将鼠标点击并聚焦在右侧的思维导图视图中。
> 3. 使用 `Enter` 新建同级主题，输入内容并回车保存；使用 `Tab` 深入下一级，全键盘无鼠标操作。
> 4. 需要补充大段背景信息时，按下 `Ctrl+Alt+Shift+C` 输入详细备注，`Ctrl+Enter` 提交，继续脑暴。

> [!WARNING]
> **多文档切换注意事项**：
> 当你切换活动笔记时，思维导图会自动读取当前处于活动状态的 Markdown 文件。如果同步模式设置为实时或防抖，请确保编辑器的内容没有语法异常以获得最佳的渲染体验。
